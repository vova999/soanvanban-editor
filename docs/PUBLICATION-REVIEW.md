# Published source scope and remaining limits

The approved public destination is vova999/soanvanban-editor. The repository includes the 66 reviewed editor/plugin/theme/UniKey/source-build inputs plus publication-specific documentation, manifests and a reproducible archive filter. It does not include the application's server/web source or private Git history.

The original upstream archives contain font files, compiled programs/libraries and nontext assets. To honor the source-only authorization, release assets retain text source/build files and applicable notices while excluding those contents. Every archive has a full exclusion report and original immutable source pin. Exact asset hashes are in RELEASE-SOURCES.json and SHA256SUMS. The archives are filtered snapshots, not unmodified upstream copies; omitted assets are required for some full builds. Upstream originals remain identified for separate licensed acquisition. Do not label this set legally cleared or a certified complete Corresponding Source offer.

The latter includes the deployed three-line background-only plugin fix and theme/build source; the source-only filtering still applies. Future branding 8 is a separate preparation and has not been image-qualified. No live source endpoint or service is changed by publication.

The generated file is not a qualified replacement, and the runtime SDK is unchanged.
