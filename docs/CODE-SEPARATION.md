# Editor/plugin source boundary

This public repository contains reviewed source-only editor/plugin inputs and source-acquisition/build metadata. It starts from an isolated history and does not disclose the private application Git history. The publication includes the original 66 reviewed inputs plus publication manifests and archive-filter tooling documented in the root README.

The independent plugin asset service uses public origins only; its protocol is in EDITOR-INTERFACE.md. Copied SDK/bridge behavior and licenses are preserved. Backend/frontend app source is excluded. The original application licenses and source offers remain unchanged; this directory/process split does not settle combined-work or future application licensing questions.

Public archives are filtered text-source snapshots with exact hashes, exclusions and immutable upstream origins. They omit fonts, compiled binaries, nontext assets and credential-pattern fixtures. They supply editable source, dependency manifests/locks and build/install scripts, while omitted inputs require separate licensed acquisition. They are not advertised as complete legally scoped Corresponding Source or a byte-identical image rebuild.

The source-only publication was explicitly authorized. Deployment, runtime SDK replacement, font redistribution and any license change were not authorized by that instruction. See PUBLICATION-REVIEW.md for the precise coverage and limits.
